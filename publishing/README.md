# AinVersia social publishing

Approved media belongs in `media/posts/` as PNG or JPEG. Do not store access tokens or private credentials in this public repository.

Publishing workflow: verify Bangladeshi legal references and Bangla artwork text; obtain explicit approval; publish media to public URLs; schedule the approved captions and media URLs through Metricool; verify scheduled entries.

Initial approved graphics: `ainversia_post_1.png` through `ainversia_post_4.png`. Images have not yet been uploaded. Do not schedule text-only substitutes.

GitHub raw image URL format after upload:
`https://raw.githubusercontent.com/MarufTahmid013/ainversia-social-media/main/media/posts/ainversia_post_1.png`

Important: A URL is valid only after the corresponding file actually exists and is publicly reachable.
